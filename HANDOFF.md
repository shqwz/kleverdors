## Производительность прокрутки (28.09.2026)
- Главная причина тормозов была в CSS: `:has(> [class*="infinity-scroller"])` в SCSS темы и
  `body:has(.kdc-cfg-on)` в custom.css. Атрибутный селектор внутри `:has()` заставлял Chrome на
  любую смену класса (lazyload у картинок, появление карточек) пересчитывать стили всего body.
  Теперь явный список классов (`$infinity-scroller-lanes` в `scss/master.scss`) и класс
  `body.kdc-cfg-page` (ставит конфигуратор). **Не возвращать атрибутные/универсальные селекторы в `:has()`.**
- `template.css` собирается Helix из `scss/` (scssoption=1): править SCSS, а не css.
- `main.js`: шапка и кнопка «наверх» меняют стили только при смене состояния; rAF-ленты
  работают, только пока видны (`huLoopWhileVisible`), пустая лента не крутится.
- Картинки: `<файл>.w480/.w800/.w1200.webp` рядом с большими фото, шаблон добавляет
  `data-srcset` (index.php), поправка для object-fit: cover — в custom.js (`lazybeforesizes`).
  Для новых фото: `python3 ../tools/make-image-variants.py images` (из public_html).
- Фон CTA на главной грузится при подъезде к секции (`.kdc-bg-in`, custom.js/custom.css).
- Hero на телефоне: высота `100svh` (не `dvh`) — иначе при скролле прячется адресная строка и фото «плывёт».
- Шаблон (index.php, onAfterRender) дописывает `?v=<дата файла>` к css/js темы и к собранному
  скрипту — без этого телефоны держали старые custom.css/custom.js из кэша nginx.
- Архив обновления без базы: `deploy/kleverdors-update-2026-09-28-mobile-perf.zip` (базу не прикладываем).
- Для выгрузки кроме прежнего списка: `templates/agentik/{index.php,js/main.js,css/template.css,scss/*.scss}`
  и все `images/**/*.w{480,800,1200}.webp`.

## Обновление архивов после правок (из public_html)
```python
import hashlib,os,zipfile
files=['templates/agentik/css/custom.css','templates/agentik/js/kdc-configurator.js','templates/agentik/js/custom.js','images/konfigurator/models.json']
ck='../_deploy/2026-09-25/checksums.sha256'
known=dict(reversed(l.rstrip('\n').split('  ',1)) for l in open(ck))
for f in files: known['./'+f]=hashlib.sha256(open(f,'rb').read()).hexdigest()
open(ck,'w').write(''.join(f'{h}  {p}\n' for p,h in sorted(known.items())))
for z in ['update_03.zip','kleverdors_site.zip']:
    zp='../_deploy/2026-09-25/'+z; tmp=zp+'.tmp'; repl={'public_html/'+f for f in files}
    with zipfile.ZipFile(zp) as zi, zipfile.ZipFile(tmp,'w',zipfile.ZIP_DEFLATED) as zo:
        for it in zi.infolist():
            if it.filename not in repl: zo.writestr(it, zi.read(it.filename))
        for f in files: zo.write(f,'public_html/'+f)
    os.replace(tmp,zp)
```
