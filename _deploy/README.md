# Перенос изменений на kleverdors.ru

## Порядок действий

### 1. Сделать резервную копию (обязательно)
- **База:** phpMyAdmin -> база `cr57261_klever` -> вкладка «Экспорт» -> «Вперёд»
- **Файлы:** через файловый менеджер хостинга заархивировать папки
  `images`, `templates/agentik`, `plugins/system/helixultimate`

### 2. Загрузить файлы (FTP / файловый менеджер)

| Что | Куда | Зачем |
|---|---|---|
| `files/images/` | `public_html/images/` (с заменой) | пережатые картинки + новые `.webp` + лёгкий фавикон |
| `files/templates/agentik/css/custom.css` | туда же | фикс дёрганья шапки, слайдер без перетаскивания |
| `files/templates/agentik/js/custom.js` | туда же | слайдер без перетаскивания |
| `files/templates/agentik/scss/theme.scss` | туда же | убрана анимация выпадания шапки |
| `files/plugins/system/helixultimate/src/Core/HelixUltimate.php` | туда же | починен кэш компиляции CSS |

### 3. Удалить на сервере
- папку `public_html/media/com_jce/` — остаток взлома (JCE не установлен)

### 4. Выполнить SQL
phpMyAdmin -> база `cr57261_klever` -> вкладка «SQL» -> вставить `migration.sql` -> «Вперёд»

### 5. Сбросить кэш
Админка Joomla -> Система -> Очистить кэш -> выделить всё -> Удалить

### 6. Проверить
Открыть сайт, обновить с очисткой кэша (Ctrl+F5 / Cmd+Shift+R). Проверить:
- главная открывается, картинки на месте
- шапка при прокрутке заливается белым без прыжка страницы
- фон слайдера не тянется пальцем, листается только по миниатюрам снизу

## Важно

`HelixUltimate.php` — файл стороннего плагина. **Обновление Helix Ultimate затрёт эту правку**,
и сайт снова начнёт пересобирать CSS на каждом запросе. После каждого обновления Helix
файл надо будет заливать заново (или применять правку повторно).

Оригиналы всех изменённых файлов сохранены в `_images_backup/`, `_HelixUltimate.php.orig`,
`_sppb_assets_before.sql`, `_sppb_id5_before.json`, `_template_style13_params_before.json`.
