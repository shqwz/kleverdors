# КЛЕВЕРДОРС — инструкции для ИИ-помощников (Codex, Claude и др.)

Сайт kleverdors.ru: Joomla 6.1 + SP Page Builder + шаблон Helix Ultimate `agentik`.
Рабочая папка сайта: `public_html/`. **Сначала прочитайте `HANDOFF.md`** — там описано, как
запустить сайт локально, что уже сделано и как устроен конфигуратор дверей.

## Жёсткие правила
- Общаться с владельцем и писать комментарии в коде — по-русски.
- Не выдумывать контент и людей; не генерировать и не подменять фото **реальных** дверей и работ.
  Интерьеры-фоны от ИИ допустимы только как оформление, и на них не должно быть дверей,
  которых нет в коллекции.
- `public_html/configuration.php` и `configuration.php.*.bak` (пароли базы) — никогда не
  читать вслух, не копировать и не коммитить.
- Архивы для выгрузки на хостинг — только файлы сайта, **без дампа базы данных**.
- Ничего не заливать на хостинг, не пушить в GitHub и не удалять файлы без прямой просьбы владельца.

## Локальный запуск (кратко)
1. Запустить Docker Desktop, затем `docker start klever_mysql` (база на порту 3307).
2. Из `public_html`: `php -d display_errors=0 -S 0.0.0.0:8000 -t . ../router.php`
3. Сайт: http://localhost:8000 (с телефона — по адресу компьютера в домашней сети).

## Частые правки
- После правки `templates/agentik/css/custom.css` или `js/kdc-configurator.js` — запустить
  `sh tools/build-min.sh` (сжатые копии `custom.min.css` и `kdc-configurator.min.js`; шаблон
  отдаёт их, только если они не старше исходника).
- Хостинг кэширует css/js/картинки на год. Поэтому при правке скрипта конфигуратора поднимать
  `?v=` в `templates/agentik/js/custom.js` (строка с `kdc-configurator.js?v=`), а новые картинки
  класть под **новым именем файла**.
- Фоны-интерьеры конфигуратора на странице коллекции: блок `room` у коллекции в
  `public_html/images/konfigurator/models.json` (файл, обрезка `top`/`bottom`, место двери `open`,
  `light`). После правки `models.json` запустить `php tools/split-models.php`.
- Картинки карточек на странице «Каталог» подменяются в `templates/agentik/index.php`
  (файлы в `public_html/images/modeli/catalog/`, у каждой лежат копии `.w480/.w800/.w1200.webp`).
