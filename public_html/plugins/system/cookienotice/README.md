# Cookie Notice for Joomla 6

A modern, lightweight and user-friendly cookie notice plugin for Joomla.
Features a clean UI, Joomla 6 event-subscriber compatibility and smart fallbacks for maximum template compatibility.

---

## ✨ Features

- Lightweight and fast
- Fully responsive
- Joomla 6 subscriber-based plugin implementation
- Web Asset Manager integration via `joomla.asset.json`
- Multi-language ready
- Custom CSS support
- Display delay control
- Flexible banner positioning
- Configurable cookie lifetime
- Works with and without Bootstrap utility classes
- Joomla backend changelog support via `changelog.xml`

## ⚙️ Installation

1. Go to **Joomla Admin → Extensions → Install**
2. Upload the plugin ZIP file
3. Enable **System - Cookie Notice**
4. Configure settings from plugin options

---

## 🏷 Title Behavior

If the **Title** field is left empty, the plugin automatically displays a translated default title.
You can override it anytime by entering your own custom title.

---

## 🎛 Configuration Options

The plugin provides the following settings:

- Title (optional)
- Message text
- Accept button text
- “Learn more” link
- Cookie lifetime (days)
- Banner position
- Display delay
- Custom CSS
